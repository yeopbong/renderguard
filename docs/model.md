# Visual observation model

The model estimates five visual observations: `clipping`, `overlap_or_occlusion`, `out_of_container`, `element_disappearance`, and `layout_displacement`. These are separate sigmoid outputs. They are not probabilities that a page contains a bug or violates the user's requirements. Contract checks and review decisions are separate evidence.

The shared MobileNetV3-Small encoder is initialized from [timm/mobilenetv3_small_100.lamb_in1k](https://huggingface.co/timm/mobilenetv3_small_100.lamb_in1k/tree/1824797e7887cbec1990e4adbd6675960a36c589), an ImageNet-1k classification model whose upstream model card explicitly declares Apache-2.0. The source revision is `1824797e7887cbec1990e4adbd6675960a36c589`; the downloaded `model.safetensors` SHA-256 is `46d2c063b18125884c48937afa4c49e18128869e52e8db96df48bf0a4d7ff697`. Downloads are verified before loading and use the non-executable safetensors format. The upstream model's ImageNet data provenance remains relevant; this release does not distribute those images or imply a new license for them. Apache-2.0 terms are reproduced in `artifacts/MODEL-LICENSE`. The paired architecture and fine-tuned weights are modifications of that generic initialization. See [Searching for MobileNetV3](https://arxiv.org/abs/1905.02244) for the architecture and [PyTorch Image Models](https://github.com/huggingface/pytorch-image-models) for the implementation.

Four shared encoder calls process local before/after crops and larger before/after context. Each produces 576 pooled channels. An ordered pair representation concatenates before, after, absolute difference, and elementwise product. Local and context representations are concatenated with 12 image-derived geometry/difference values and passed through a 128-unit ReLU head, dropout 0.15, and five logits. The model sees no DOM rules, mutation names, source identifiers, filenames, split flags, ground-truth boxes, or review decisions.

The shared TypeScript preprocessing is authoritative. Inputs are RGB NCHW float32 at 96 × 96. PNG alpha is composited onto white; deterministic bilinear letterboxing retains the complete crop and uses the ImageNet mean and standard deviation. No center crop is applied. Crops include explicit white padding outside valid page regions. The context crop adds at least 40 pixels and otherwise 65% of the candidate's larger dimension to each edge. The local crop adds at least 8 pixels and otherwise 8%. Candidate geometry, masks, height differences, and normalization are specified in `core/index.ts`, version `rgba-diff-rle-letterbox-v1`. Fine print can become unresolved when a large candidate is reduced to 96 pixels; this model does not guarantee recognition below that scale.

Training uses masked binary cross-entropy. Positive weights are computed from training labels only, capped at 10. The head receives two warmup epochs of generic visual features. Four subsequent epochs update the head and the last three encoder stages with AdamW. The fixed-feature baseline leaves all encoder parameters frozen. BatchNorm running statistics remain unchanged in every experiment, including fine-tuning. Gradient totals, encoder weight deltas, epoch losses, development metrics, and exact safetensors reload comparisons are written to the experiment records.

Three fixed seeds, 17, 29, and 43, are used for each primary neural configuration. The released local-plus-context model is selected by development macro PR-AUC. Calibration and test data do not select the seed. The manifest records the actual training source commit, source hashes, upstream weight hash, data and split hashes, safe-weight hash, ONNX hash, and preprocessing version.

Each sufficiently supported class receives temperature-and-bias logistic calibration on the separate calibration families. At least 15 known positives and 15 known negatives are required; other classes remain explicitly uncalibrated. The calibrated target is the frequency of an observation on this synthetic candidate domain. Calibration is invalidated by any model or preprocessing change. Brier scores, ECE bins, sample counts, and reliability figures are available with the experiment artifacts. A low ECE is not evidence against missed candidates or missed observations.

The ONNX artifact uses opset 17 and the inputs `local_before`, `local_after`, `context_before`, `context_after` (`N×3×96×96`) and `geometry` (`N×12`), returning `logits` (`N×5`). The browser runs the actual graph with ONNX Runtime Web WASM CPU in a Worker. Missing or mismatched model assets are errors. A numerical PyTorch/ONNX check is necessary but distinct from the browser PNG/candidate/tensor/output parity checks.

Explicit feedback updates use `python -m ml.feedback --feedback feedback.json --output candidate-model`. Only corrected observation labels are used. The encoder remains frozen; retained original training examples are mixed with corrections, while a separate retained development subset compares old and new capability. A candidate is eligible only if development macro PR-AUC decreases by no more than 0.03. Eligibility does not activate a model: the user must select it. The old version remains available for rollback. Feedback changes invalidate calibration. No click silently trains the model, and unchanged predictions are never rewritten.

Reproduce the full baseline and training suite with `python -m ml.train --epochs 6`. Use `--device cpu` for CPU or `--device mps` on supported macOS hardware. The first invocation retrieves verified generic weights; cached training and application inference work offline after preparation.
